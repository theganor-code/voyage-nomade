VOYAGE NOMADE — VERSION iPHONE

Cette version est préparée pour être utilisée comme une vraie application web sur iPhone.

IMPORTANT : ne pas ouvrir index.html directement dans l'app Fichiers. Cela affiche seulement le fichier comme un document et casse la mise en page.

Pour l'utiliser sur iPhone :
1. Mettre le contenu de ce dossier sur un hébergement web HTTPS (GitHub Pages convient et ne demande pas Netlify).
2. Ouvrir l'adresse du site dans Safari sur l'iPhone.
3. Dans Safari : bouton Partager -> Sur l'écran d'accueil -> Ajouter.
4. L'icône Voyage Nomade pourra alors être lancée comme une application.

PHOTOS iPHONE :
- JPG/JPEG : pris en charge.
- HEIC/HEIF : conversion automatique en JPEG lorsque le convertisseur est chargé.
- Les photos sont réduites avant stockage pour éviter de saturer le stockage du navigateur.

NETLIFY : aucun fichier de configuration Netlify et aucune commande Netlify n'est nécessaire dans cette version.
